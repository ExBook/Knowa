从录题到复盘，一套完整学习工作流

ExLocal 不是只存题的表格，而是把录入、练习、回顾、笔记和迁移打通的本地学习系统。

01

富文本题目编辑器

支持图片、公式、行内代码、代码块、解析、章节、节与知识点索引，适合录入复杂学科题目。

02

Markdown 批量导入

模板按钮、实时预览、格式提醒与公式渲染，让大量题目录入更快，也更不容易误操作。

03

练习与考试模式

可按顺序、随机、章节或知识点刷题；支持统一交卷、未答题提示和自定义倒计时。

04

错题、收藏与笔记

按题库或章节组织复盘内容，支持选择性重做、编辑笔记和导出有笔记的题目。

05

做题记录回顾

按日期和题组抽屉展示历史练习，能看到每次提交的答案、正确答案和解析。

06

专业导出

题库、错题、收藏、笔记和完整数据都可导出；PDF 带 ExLocal 标识，适合打印和分享。

桌面端为长期资料准备

桌面应用保留 Web 版的轻量体验，同时增加系统级图标、文件关联、本地备份目录选择和跨设备迁移能力。默认备份路径根据平台生成，也可以改到同步盘或资料目录。

  • `.exlocal` 完整备份包含图片、设置、记录和笔记。
  • `.exbank` 题库包适合分享单个题库。
  • 桌面端文案会提示固定本地目录，Web 预览版使用下载导出。

快速上手

从空白到第一轮复盘，只需要四步。

1

创建题库

设置名称、标签和浅色卡片颜色，让不同科目更容易区分。

2

录入或导入题目

少量题目用富文本编辑器，大量题目用 Markdown 模板和实时预览。

3

选择刷题方式

按章节、节、知识点、顺序或随机练习，也可以开启考试倒计时。

4

复盘与迁移

查看题组记录、整理笔记，最后导出 PDF 或 `.exlocal` 完整备份。
