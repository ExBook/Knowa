# ExLocal Website

Static marketing and tutorial site for Cloudflare Pages.

## Commands

```bash
npm run site:dev
npm run site:build
npm run site:preview
```

## Cloudflare Pages

- Build command: `npm run site:build`
- Output directory: `website/dist`
- Node version: `22`

Update download and demo links in `index.html` when release tags or deployment routes change.
