使用教程

从空白题库到第一轮复盘

这份教程按真实学习流程编排。你可以先用在线体验练一遍，再把自己的资料迁移到桌面端长期维护。

安装与数据 创建题库 录入题目 Markdown 导入 开始刷题 复盘记录 导出与备份 桌面端建议

1. 安装与数据位置

桌面端下载后直接安装。Knowa 的运行数据保存在本机，桌面端还可以在设置页指定固定备份目录。

  • macOS：建议下载 Universal 包，兼容 Apple Silicon 与 Intel Mac。
  • Windows：普通电脑选择 x64 安装包。
  • Linux：优先使用 AppImage，或按发行版选择 deb/rpm。

2. 创建你的第一个题库

在题库页点击创建题库，填写名称、描述、标签和卡片颜色。题库卡片会显示题目数量、标签和做题进度条，后续搜索结果也会按题库抽屉组织。

建议按考试科目、课程或资料来源建立题库，例如“高等数学”“数据结构”“教师资格证”。

3. 录入题目

进入题库详情页后点击添加题目。题型支持单选、多选和判断。题目内容可以包含富文本、行内代码、代码块、行内公式、整行公式和图片。

  • 章节、节、知识点用于后续定向刷题。
  • 图片可以调整缩放比例和对齐方式。
  • 解析建议写出关键思路，复盘时比只看答案更有价值。

4. Markdown 批量导入

适合一次性整理多道题。导入窗口提供不同题型模板，右侧实时预览会渲染代码和公式，格式错误会给出提醒。

### 单选题：极限基础
章节：高等数学
节：函数与极限
知识点：等价无穷小
标签：基础, 高频

题目：
当 x -> 0 时，sin x 与 x 的比值极限是多少？

A. 0
B. 1
C. 无穷大
D. 不存在

答案：B

解析：
由等价无穷小可知 $\\sin x \\sim x$，所以极限为 1。

5. 开始刷题

刷题前可以选择模式、顺序和筛选范围。练习模式适合即时纠错，考试模式适合统一交卷。倒计时开启后，时间到会强制提交。

  • 题目过长时标题栏固定，内容区滚动。
  • 未交卷返回时会确认，未交卷不会写入做题记录。
  • 刷题页可调整阅读字体风格和字号。

6. 复盘错题、收藏和笔记

答题完成页会显示题号导航，并用颜色区分正确、错误和未答。错题集、收藏和我的笔记都支持搜索、分组、选择性重做和导出。

我的笔记更适合记录“为什么会错”和“下次怎么判断”，不要只复制解析。

7. 导出、打印和迁移

题库、收藏、错题和笔记都支持选择性导出。PDF 会带 Knowa 标识，适合打印成试卷或整理成学术笔记。

  • .exbank：单个题库交换包。
  • .exlocal：完整数据备份，包含图片、记录、设置和笔记。
  • 换设备时先导出完整备份，再在新设备导入。

8. 桌面端长期使用建议

在设置页指定固定备份目录，例如同步盘或专门的学习资料目录。这样每次导出完整备份都能进入同一个地方，便于版本管理和跨设备迁移。

macOS: ~/Library/Application Support/com.exbook.exlocal/backups Windows: %LOCALAPPDATA%\com.exbook.exlocal\backups Linux: ~/.local/share/com.exbook.exlocal/backups
