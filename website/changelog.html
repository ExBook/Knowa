v0.1.0 2026-05-29

第一个桌面端公开版本

这个版本完成了 Knowa 的核心学习闭环：建题库、录题、导入、刷题、交卷、复盘、笔记、错题、收藏、导出和完整备份。

新增功能

  • 支持单选、多选、判断题，以及章节、节、知识点索引。
  • 支持富文本题干、选项、解析和笔记，包含图片、公式和代码。
  • 支持 Markdown 模板导入、实时预览、格式提醒和公式渲染。
  • 支持练习模式、考试模式、统一交卷和自定义倒计时。
  • 支持答题完成页题号导航、颜色正误标识和题目回顾。
  • 支持收藏、错题集、我的笔记和题组做题记录。

导出与桌面端

  • 支持题库、收藏、错题和笔记的选择性导出与打印。
  • 支持 `.exbank` 题库包和 `.exlocal` 完整备份包。
  • 完整备份包含题库、题目、记录、设置、笔记和图片。
  • 桌面端支持默认本地备份目录和用户自定义目录。
  • GitHub Release 生成 macOS、Windows 和 Linux 安装包。

后续改进

  • 优化 macOS 打包为 Universal，减少 Intel Runner 排队问题。
  • 优化桌面端启动白屏和 macOS 关闭按钮行为。
  • 持续改进官网、示例题库、教程和发布说明。

桌面体验和资料迁移增强

下一阶段会继续提升桌面端原生体验、导出排版、示例题库质量和长期资料维护能力。

  • 更丰富的教程截图和真实使用场景。
  • 持续补充导出格式和打印版式。
