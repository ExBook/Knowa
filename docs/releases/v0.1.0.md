# Knowa v0.1.0 发布说明

发布日期：2026-05-29

Knowa 是一款本地优先的个人题库与刷题应用，适合备考、教学资料整理、错题复盘和长期知识管理。题库、图片、做题记录、收藏、错题集、笔记和备份都优先保存在用户自己的设备中。

## 本次发布重点

- 支持题库创建、题目编辑、题库详情统计和题库进度展示。
- 支持单选题、多选题、判断题，以及富文本题干、选项、解析和笔记。
- 支持 Markdown 批量导入，包含模板、实时预览、公式和代码渲染。
- 支持按章节、节、知识点、顺序和随机方式刷题。
- 支持练习模式、考试模式、自定义倒计时和统一交卷。
- 支持答题完成页、题号导航、正误颜色、正确答案和解析回顾。
- 支持收藏、错题集、我的笔记、做题记录和题组重做。
- 支持题库、收藏、错题、笔记的选择性导出与打印。
- 支持 `.exlocal` 完整数据备份，包含题库、题目、记录、设置、笔记和图片。
- 支持 Tauri 桌面端本地备份目录、文件关联和跨设备迁移。

## 下载建议

- macOS：优先下载 Universal DMG，兼容 Apple Silicon 和 Intel Mac。v0.1.0 当前已有 Apple Silicon 包，Universal 包会在下一次工作流发布中生成。
- Windows：普通电脑下载 x64 安装包；ARM 设备可尝试 ARM64 安装包。
- Linux：优先选择 AppImage；也可以按发行版选择 deb 或 rpm。

## 数据说明

Knowa 默认本地存储。桌面端可以设置固定本地备份目录，并导出 `.exlocal` 完整备份包。换设备时导入该备份包即可衔接题库、记录、笔记和图片。

## 已知限制

- 当前版本仍以本地单机学习工作流为核心，暂不包含云同步和账号系统。
- 在线体验页不面向手机端开放，移动端会提示用户前往桌面端或大屏幕设备。
- v0.1.0 首次发布时 macOS Intel 单独构建曾在 GitHub Runner 中长时间排队；后续工作流已改为 macOS Universal 构建。
